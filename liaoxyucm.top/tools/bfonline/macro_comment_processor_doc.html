1. 简介

这是一个 Brainfuck 预处理器，用于在 Brainfuck 代码中加入注释和宏。 预处理器读取源代码，删除注释、展开宏调用，然后输出处理后的 Brainfuck 代码。

核心处理函数签名为： 

export default function macro_comment_process(code: string): [boolean, string]
  • 返回值第一个元素表示语法是否正确（true / false）。
  • 第二个元素是处理结果字符串（语法正确时有效，否则为空字符串）。

2. 语法说明

2.1 注释

使用 C 风格块注释：

/* 注释内容 */

注释内容会被删除，不会出现在输出中。

注意

不支持 // 行注释，也不支持嵌套注释。例如 /* /* */ */ 会被解析为第一个 /* 到第一个 */ 结束，后面的 */ 会作为普通字符输出。

示例

输入
[Hi.] /* 这是一个注释 ++--. */
输出
[Hi.]

2.2 宏定义

语法：

$宏名{宏体}
  • $ 必须紧贴宏名，中间不能有空白。
  • 宏名可以是任意一个字符；从 $ 之后到 { 之间的所有字符都视为宏名。
  • { 和 } 包围宏体。
  • 宏体中使用 @ 表示调用时传入的参数占位符。
  • 宏体不能包含 }，否则会提前结束宏定义。

示例

输入
$square{>@[<@>-]<.}
说明
定义宏 square
宏体为 >@[<@>-]<.
@ 为参数占位符

2.3 宏调用

语法：

$宏名(参数)
  • $ 必须紧贴宏名。
  • 参数写在 ( 和 ) 之间。
  • 参数不能包含 )，否则会提前结束参数列表。
  • 调用时，宏体中的所有 @ 都会被替换为参数。
  • 支持零参数调用，即 $foo()，此时参数为空字符串。
  • 不支持多参数宏；, 会被视为参数的一部分，而非分隔符。

示例

输入
$square(++++++)
输出
>++++++[<++++++>-]<.

3. 完整示例

输入
[Hi.] /* ++--. */
$square{>@[<@>-]<.}
$square(++++++)
输出
[Hi.]

>++++++[<++++++>-]<.
展开过程

宏调用 $square(++++++) 中，宏体 >@[<@>-]<. 里的两个 @ 都被替换为 ++++++，得到 >++++++[<++++++>-]<.。

4. 详细规则

项目 规则
宏名 从 $ 之后到 {（定义）或 (（调用）之间的所有字符，可以是任意字符
$ 与宏名 必须紧贴，中间不能有空白或其他字符
宏体（定义） 不能包含 }，可以包含除 } 之外的任意字符
参数（调用） 不能包含 )，可以包含除 ) 之外的任意字符
参数占位符 @，宏体中的所有 @ 都会被替换为同一参数
多参数 不支持，, 视为参数的一部分
零参数 支持，$foo() 参数为空字符串
宏内定义/调用宏 不支持，宏体内不能定义或调用另一个宏
注释 /* ... */，不支持 //，不支持嵌套
未定义宏调用 展开为空字符串（不报错）

5. 实现细节

可以在 GitHub 上查看完整 TypeScript 实现

5.1 处理流程

  1. 遍历输入字符：使用 pointer 逐个扫描 code。
  2. 遇到 $：
    • 持续读取字符直到遇到 { 或 (，这些字符构成宏名。
    • 继续读取字符直到遇到 } 或 )，这些字符构成宏体或参数。
    • 如果是 }，说明是宏定义，存入 macros。
    • 如果是 )，说明是宏调用，取出宏体并替换 @ 后追加到 result。
    • 若宏名未定义，macros.get() 返回 undefined，通过 || "" 展开为空字符串。
  3. 遇到 /：如果下一个字符是 *，进入注释跳过逻辑；否则作为普通字符输出。
  4. 其他字符：直接追加到 result。
  5. 异常处理：任何越界或意外情况被 catch 捕获，返回 [false, ""]。

6. 限制与注意事项

限制 说明
宏名任意字符 宏名可以包含空格、换行、$、/ 等任意字符，只要它们出现在 $ 和 { / ( 之间
宏体不能含 } 定义宏时，} 会立即结束宏体，无法在宏体内使用
参数不能含 ) 调用宏时，) 会立即结束参数，无法在参数内使用
宏内不能嵌套宏 宏体内不能定义或调用另一个宏，$ 会被当作普通字符处理
无多参数 只支持单个参数，, 不具分隔语义
注释不支持嵌套 /* /* */ */ 会在第一个 */ 结束
不支持 // 行注释不被识别，/ 后跟非 * 时按普通字符输出
未定义宏静默展开 调用未定义的宏不会报错，而是展开为空字符串
边界行为提示

由于宏名和参数读取依赖 {、(、}、) 作为终止符， 如果输入中 $ 后面没有出现这些字符，指针会持续前进直到越界，触发 catch，返回 [false, ""]。

7. 错误处理

函数通过 try / catch 捕获处理过程中的异常。当出现以下情况时，返回 [false, ""]：

  • $ 后未找到 { 或 (，导致指针越界。
  • 读取宏体或参数时，未找到对应的 } 或 )，导致指针越界。
  • 注释未闭合，且后续扫描越界。

语法正确时，返回 [true, result]，其中 result 是处理后的字符串。

7.1 未定义宏的行为

调用未定义的宏不会导致语法错误。实现中使用： 

(macros.get(storaged_name) || "").replaceAll("@", storaged_body)

因此未定义宏会被展开为空字符串，函数仍返回 [true, result]。
