基本信息

键 值
接口地址1 https://api.liaoxyucm.top/lang/bf.php
接口地址2 https://lang.llcm.top/bf.php
主机提供商 MNBT
请求方式 GET
返回格式 application/json

参数

注: 所有参数都不是必传的, 默认值是空字符串

名称 说明
code Bf代码
input 提供输入给Bf代码
preprocessor 若值为 macro_comment , 则使用宏和注释预处理器

返回

名称 类型 说明
success boolean 代码无误且单个循环不超过 131071 次则为 true , 否则为 false
text string 若 success 为 true , 则为程序运行的结果, 否则为失败原因

请求示例

?code=%24sq%7B%3E%40%5B%3C%40%3E-%5D%3C.%7D%24sq(%2B%2B%2B%2B%2B%2B)&preprocessor=macro_comment

预期返回 {"success":true,"text":"$"}
