liaoxyucm.top的网站备份和问题跟踪器，请在这里发布issues或申请友链交换，但**不接受任何PRs**

----------------------------

## 本仓库作用

1. **最主要**: 为一切行为**可能导致网站数据丢失**的起容灾作用
2. 通过 Git 可以追溯历史的特性, 该仓库也可以用作查阅网站历史特定时间点的数据
3. 申请友链交换

## 备份规则

1. 必须以线上的基本一致
2. 一对页面基本相同的, 按需求只备份其中一个 \(api.liaoxyucm.top/lang 和 lang.llcm.top\)
3. 整个站点有单独 GitHub 仓库的, 不备份 \(llcm.top, st.llcm.top 等\)
4. 从备份恢复的意图为网站早期状态时光机, 不备份 \(lcmtop-thepast.rth1.xyz 等\)
5. 已 301 的页面, 不备份 \(history.liaoxyucm.top 等\)
